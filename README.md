# Description
NASA-Daily is a simplistic news brief website made for sharing a nasa story every day. It includes a picture and a paragraph explaining it. The website has a new story every day! 

# Features
* daily story
* image Gallery
* news page
* date
* live iss tracker
* space weather
  
# Update!

* weather
* news
* live  

Since the last ship I added 3 tabs, weather, news, and live. weather shows current space weather and chance of auora. news has the top headlines and links connected to them. Live has the current position of the ISS in space and a map so you can see where it is relative to you
